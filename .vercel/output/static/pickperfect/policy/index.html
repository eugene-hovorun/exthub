The short version

PickPerfect keeps your data on your device. The extension does not collect personal information, send usage data anywhere, or run hidden tracking. Premium payments go through ExtensionPay.

What PickPerfect stores on your device

PickPerfect saves a small amount of local data so the extension works the way you expect each time you open it. That data lives in chrome.storage.local on your device.

  • Color history for the last 20 colors you picked, including the value and timestamp
  • Format preference so the popup remembers whether you prefer HEX, RGB, or HSL
  • Premium status so paid features unlock quickly without re-checking on every open

PickPerfect does not send this data to us. The only exception is premium verification through ExtensionPay, which is covered below.

What PickPerfect collects

PickPerfect does not collect personal data, usage analytics, telemetry, or tracking identifiers. If you use the free extension and never buy premium, there is nothing being sent to our server because there is no server involved in the core workflow.

Why the extension asks for permissions

PickPerfect asks for a narrow set of Chrome permissions for specific features.

  • storage keeps your color history, format choice, and premium status on your device
  • activeTab is used only when you run page palette extraction on the current page
  • scripting injects the one-time extraction script for that palette feature and nothing more

The main color picker uses the browser's native EyeDropper API. It does not need a persistent content script, and it does not read arbitrary page content in the background.

Premium features

Premium access is a one-time purchase. The paid features still run locally inside the extension.

  • WCAG Contrast Checker runs locally in the popup
  • Tailwind Color Mapping runs locally in the popup
  • Page Palette Extraction reads visible CSS color values from the current tab when you explicitly click the extraction button

That extraction flow does not read your form submissions, cookies, or browsing history. It only analyzes color values needed to build the page palette.

Third-party services

PickPerfect uses ExtensionPay for premium checkout and license verification. ExtensionPay may use Stripe to process payments. You can read their privacy policy here: extensionpay.com/privacy.

Outside of payments, PickPerfect does not use analytics tools, ad networks, or hidden third-party scripts.

What PickPerfect does not do

PickPerfect does not track you, profile you, sell your data, or run passive monitoring in the background. It does not read your browsing history, and it does not keep a persistent content script attached to pages.
